Summary (simple terms)
•	This is a console single‑player Battleship game: you (Player1) vs the computer (Player2).
•	The program sets up two 10×10 boards, places 5 ships for each player (manually or randomly), then alternates turns until one side has all ships sunk.
•	It prints boards and messages to the console and logs each move and final stats to Battleship.log.
